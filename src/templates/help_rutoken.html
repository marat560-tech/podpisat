Как установить Рутокен Плагин

Подпись на Рутокен ЭЦП 3.0 (его берут в основном для ЕГАИС) работает в браузере через Рутокен Плагин. Подпись на Рутокен Lite работает через КриптоПро — что для неё нужно. Нужны две вещи: сама программа и расширение для браузера. Всё бесплатно, займёт минут пять.

{% call g.step(1, 'Скачайте Рутокен Плагин', 'download') %}

На официальном сайте: rutoken.ru — Рутокен Плагин. Выберите вашу систему — обычно Windows.

{% endcall %} {% call g.step(2, 'Установите программу', 'install') %}

Запустите скачанный файл и нажимайте «Далее» до конца. Если Windows спросит разрешение на изменения — ответьте «Да».

{% endcall %} {% call g.step(3, 'Добавьте расширение в браузер', 'puzzle') %}

Откройте «Адаптер Рутокен Плагин» в магазине расширений и нажмите «Установить». Подходит для Google Chrome, Яндекс Браузера и Microsoft Edge.

{% endcall %} {% call g.step(4, 'Перезапустите браузер', 'restart') %}

Закройте браузер полностью — все окна — и откройте снова. Без этого расширение может не заработать.

{% endcall %} {% call g.step(5, 'Вставьте Рутокен и проверьте', 'check') %}

Вставьте Рутокен в USB-разъём и откройте проверку компьютера: пункты про Рутокен должны быть с галочкой, а ваша подпись — в списке.

{% endcall %}

Если не получилось

  • Компьютер не видит сам Рутокен — установите драйверы из центра загрузок Рутокена и вставьте токен в другой разъём, лучше прямо в компьютер, а не через удлинитель.
  • Расширение установлено, но проверка его не видит — проверьте, что оно включено: меню браузера → «Расширения».
  • Всё равно не работает — подпись не видна: что делать или позвоните: {{ phone }}, подключимся и настроим.
