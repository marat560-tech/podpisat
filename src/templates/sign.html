Нужна подпись с видимым штампом в PDF?

Для PDF есть подпись со штампом прямо на странице — оттиск по ГОСТ Р 7.0.97, ставится мышкой в любое место. А получить и проверить подписанный файл можно здесь же.

Что получится

Архив имя_файла.zip, внутри — ваш исходный файл без изменений и файл подписи имя_файлаSGN1.sig (формат CMS, ГОСТ Р 34.10-2012). Такой архив принимают инспекции и системы, которые работают с файлами КриптоАРМ и СБИС. Если файлов несколько — каждый в своём архиве, а кнопка «Скачать всё» соберёт их в один.

Не видно подписи?

  1. Рутокен ЭЦП 3.0 из налоговой — нужны две вещи:
    1. программа Рутокен Плагин — скачайте и установите;
    2. расширение для браузера Адаптер Рутокен Плагин — нажмите «Установить» (подходит для Chrome, Яндекс Браузера и Edge).
    Затем закройте и снова откройте браузер.
  2. Подпись через КриптоПро — нужен установленный КриптоПро CSP и ещё две вещи:
    1. программа КриптоПро ЭЦП Browser plug-in;
    2. расширение для браузера CryptoPro Extension for CAdES Browser Plug-in (Chrome, Яндекс Браузер, Edge).
    Затем закройте и снова откройте браузер.
  3. При первом обращении плагин спросит, доверять ли сайту подписатьэцп.рф, — нажмите «Да» / «Разрешить».
  4. Не получается — позвоните {{ phone }}, поможем удалённо.
