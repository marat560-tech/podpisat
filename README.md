# подписатьэцп.рф

Статический сайт: подпись файлов в браузере (Рутокен Плагин и КриптоПро ЭЦП Browser plug-in),
подпись PDF со штампом, проверка подписи, страница программы удалённой помощи Help4x
и заглушки разделов «в разработке» (ЕГАИС, Меркурий, отчётность).

## Сборка

```
python3 build.py        # src/ + files/ -> site/
```

`files/` — большие файлы, которые раздаются с нашего сервера: `Help4x-*.exe`, архив исходников Help4x
(требование AGPL) и `help4x.json` с версией. В git они не хранятся.

## Подпись

`src/static/sign.js` — всё на стороне браузера, файл на сервер не отправляется.
Результат: отделённая подпись CMS CAdES-BES, ГОСТ Р 34.10-2012, упаковка как у СБИС/КриптоАРМ:
`<имя>.zip` = `<имя>` + `<имя без расширения>SGN1.sig`.

Библиотеки: `rutoken.min.js` (Актив, BSD), `jszip.min.js` (MIT). `cadesplugin_api.js` скачивается
с сайта КриптоПро при установке.

## Подпись PDF со штампом

`src/static/pdfsign.js` (страница `/pdf`) — просмотр через PDF.js, штамп ставится мышкой на любые страницы.
`src/static/pdfinc.js` дописывает в конец PDF изображение штампа, поле подписи и подпись
(инкрементальное обновление, PAdES, `/SubFilter /ETSI.CAdES.detached`), поэтому прежние подписи
в документе остаются действительными. Работает и со старыми таблицами xref, и с xref-потоками.
`src/static/stamp.js` рисует штамп по ГОСТ Р 7.0.97-2025 (4 стиля, цвета, логотип) — без надписей сервиса.

## Проверка подписи

`src/static/cmsverify.js` (страница `/verify`) — разбор CMS и проверка ГОСТ Р 34.10-2012 (256/512)
на BigInt, хэш «Стрибог» — `vendor/gost/gostDigest.min.js`. Принимает подписанный PDF,
.sig/.p7s (DER или base64) с документом, присоединённую подпись, архивы .zip.

## Пакетная подпись

На `/sign` можно выбрать несколько файлов: PIN Рутокена вводится один раз, на выходе архив на каждый файл
и общий архив со всеми файлами и подписями. Общая часть работы с плагинами — `src/static/esign.js`.

## Установка на Windows 10

Сервер: Caddy как служба Windows (`deploy/install.ps1`), HTTPS-сертификат получает сам.
Нужно: DNS A-записи `подписатьэцп.рф` и `www.подписатьэцп.рф` на белый IP, проброс TCP 80 и 443 на сервер,
разрешение входящих 80/443 в брандмауэре Windows.
